# Чек-лист сдачи (регламент FEIS Game Jam)

## itch.io страница
- [ ] Название игры
- [ ] Обложка проекта
- [ ] Скриншоты или гифка геймплея
- [ ] Краткое описание (1–3 абзаца)
- [ ] Управление описано текстом
- [ ] Использованные ассеты с авторами (ссылка на ASSETS.md)
- [ ] Ссылка на публичный репозиторий
- [ ] Раздел об использовании ИИ и инструментов

## Репозиторий
- [ ] Репозиторий公開тый (доступен по ссылке со страницы itch.io)
- [ ] Файл LICENSE в корне
- [ ] Файл ASSETS.md в корне (перечень сторонних ассетов, авторов, лицензий)
- [ ] Первый коммит не ранее 18:00 23.10.2026 (после объявления темы)
- [ ] Нет секретов, ключей доступа и персональных данных

## Отчёт об ИИ
- [ ] Файл docs/ai-report.md заполнен (150–500 слов)
- [ ] Инструменты и модели указаны
- [ ] Зоны применения ИИ описаны
- [ ] Пример эффективного приёма приведён
- [ ] Указано, что сделано без ИИ
- [ ] Авторы и лицензии сторонних ассетов (ссылка на ASSETS.md)

## Игра
- [ ] Запускается в браузере (HTML5), без скачивания дополнительного ПО
- [ ] Полный игровой цикл: начало → процесс → завершение
- [ ] Нет критических багов (блокирующих запуск или прохождение)
- [ ] Нет запрещённого контента (п. 3.5 регламента: политика, религия, дискриминация, насилие 18+, оскорбления реальных лиц, наркотики, алкоголь, табак, нарушение законодательства РБ)
