# Отчёт об использовании ИИ

## Проект: ПОСЛЕДНИЙ ЧЕЛОВЕК (FEIS Game Jam)

## Инструменты и модели
- Игровой движок: собственный на HTML5 Canvas 2D + чистый JavaScript (ES2020+), без шага сборки и внешних библиотек.
- Звук: **HTML5 Audio** (17 SFX mp3/wav + 5 музыкальных треков mp3), первый клик разблокирует autoplay policy. Web Audio API синтез не используется в финальной версии.
- Графика: все ассеты созданы художником команды вручную (скетчи, линейка), затем доработаны/апскейлены/стилизованы через ИИ-инструменты (Stable Diffusion img2img, Midjourney). Полные права принадлежат команде.
- Музыка и звук: композиция/рендер с возможной помощью ИИ-ассистентов (Suno, Stable Audio) + ручной мастеринг.

## Зоны применения ИИ
- Тексты туториалов (4 контекстных), справки по статам, подтверждения конца дня, меню помощи.
- Названия спец. заданий (`[ГРУППА]`, `[СОЛО-ЭПИК]`), типов заданий (`stables`, `lieschool`), видов монстров (`orc`, `troll`).

## Пример эффективного приёма
Пример промта для улучшения для скетчей ассетов:
dark fantasy gothic horror, photorealistic, highly detailed, cinematic lighting, deep shadows, blood-red accents, muted colors, ominous atmosphere, gothic architecture, tattered cloaks, cracks, blood stains, glowing eyes, 8k, ultra-detailed, square composition, centered, isolated on dark background. 

## Что сделано без ИИ
- **Весь исходный код в `src/`** (`main.js`, `game.js`, `input.js`, `renderer.js`, `assets.js`, `audio.js`, `utils.js`, `models.js`, `content.js`) — программист писал, ИИ помогал: рефакторинг, автодополнение, поиск опечаток, предложение вариантов структуры, перевод комментариев.

- **Структура проекта и точка входа `index.html`** — разметку писал программист, ИИ подсказывал атрибуты доступности/мета-теги.

- **Игровая математика (`models.js`)** — формулы придумал геймдизайнер, программист реализовал, ИИ помогал перепроверять логику и писать бойлерплейт.

- **Базовый чек-лист и аудиоплан** (`docs/design/checklist.md`, `docs/design/audio.md`) — структуру задал QA, ИИ оформил в маркдаун, дополнил пунктами из регламента.
## Авторы и лицензии сторонних ассетов
См. `ASSETS.md` в корне репозитория. Все графические и аудио ассеты — оригинальные работы команды (ручной скетч → ИИ-доработка), лицензия `Proprietary (наши права)`.
