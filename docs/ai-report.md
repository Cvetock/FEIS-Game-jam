# Отчёт об использовании ИИ

## Проект: ПОСЛЕДНИЙ ЧЕЛОВЕК (FEIS Game Jam)

## Инструменты и модели
- Игровой движок: собственный на HTML5 Canvas 2D + чистый JavaScript (ES2020+), без шага сборки и внешних библиотек.
- Звук: Web Audio API (синтез коротких SFX без аудиофайлов).
- Генерация текстов (концепт, сценарий, спецификации, чек-листы): с использованием ИИ-помощника с последующей ручной правкой и утверждением командой.
- Графика: пиксель-арт 32×32, планируется ручная отрисовка с возможной ИИ-генерацией базовых форм и дорисовкой вручную.
- Музыка и звук: готовые лицензионно-чистые треки (CC0/CC-BY) из бесплатных библиотек.

## Зоны применения ИИ
- Написание концепта игры (CONCEPT.md) и сценария прохождения (SCENARIO.md).
- Составление спецификаций ролей (docs/specs/*) и чек-листов сдачи (docs/checklist.md).
- Генерация идей имён монстров, названий заданий, предметов.
- Подбор палитры и стилистических решений.

## Пример эффективного приёма
Концепт «ПОСЛЕДНИЙ ЧЕЛОВЕК» был сформулирован за 30 минут через итеративное уточнение промпта: сначала предложена общая идея «управление монстрами», затем уточнён сеттинг (последний человек открывает агентство трудоустройства нечисти), затем расписаны основные экраны и статы. Итоговый текст отредактирован вручную под требования геймджема.

## Что сделано без ИИ
- Весь исходный код игры в `src/` (main.js, game.js, input.js, renderer.js, assets.js, audio.js, utils.js).
- Структура проекта и точка входа `index.html`.
- Файл `LICENSE` (MIT).
- Базовый чек-лист и аудиоплан (docs/design/checklist.md, docs/design/audio.md).
