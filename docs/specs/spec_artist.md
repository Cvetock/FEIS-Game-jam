# Спецификация: Художник (Арт-директор)
## Проект: ПОСЛЕДНИЙ ЧЕЛОВЕК

## Твоя роль в команде
Ты отвечаешь за единство визуального стиля. Игра — стратегия с интерфейсом агентства монстров, поэтому графика должна быть читательной, аккуратной и соответствовать тематике «последний человек среди нечисти». Особое внимание: UI для **собеседований**, **отчётов монстров (с текстом)**, **индикаторов перехвата заданий**, **финального тендера**.

## Стек и форматы
- HTML5 Canvas 2D
- PNG (pixel-art) или SVG (вектор)
- Единый стиль для всех ассетов
- ИИ-генерация разрешена, но с ручной доработкой (для отчёта об ИИ)

## Что именно ты должен сделать

### День 1 — Style guide и базовые ассеты
1. **Style guide (`docs/art-style.md`):** утвердить направление (pixel-art 32×32 или плоский вектор), палитру (3–5 базовых цветов + акценты, HEX), правила читаемости.
2. **Структура папок:** `assets/art/sprites/`, `assets/art/ui/`, `assets/art/bg/`, `assets/art/fx/`.
3. **Базовые спрайты:**
   - Портреты монстров по видам (Гоблин, Оук, Скелет, Слизь, Импу, Тролль, Вампир) — 32×32 или 64×64.
   - **Эмоции/состояния монстров:** нейтральный, довольный (успех), переубеждённый (overkill), уставший/раненый, подозрительный (ложь в отчёте), ушедший (не прошёл собеседование).
   - Иконки видов заданий (ферма, караван, пещеры, руины).
   - Иконки предметов (дубина, щит, амулет, зелье).
   - **Иконки предпочтений (для QA/отладки, в игре скрыты):** сердечко (работает с кем-то), зачёркнутая пещера, символ нежити.
   - Фон кабинета агентства (стол, доска заказов, карта).
   - **Фон финального тендера:** стол переговоров, герой-директор в костюме, монстры с обеих сторон.
4. **UI-элементы:** кнопки,枠ки списков, прогресс-бары, иконки статов (сила, ловкость, интеллект, удача).
5. **Специфичные UI для новых механик:**
   - **Экран собеседования:** карточка кандидата с портретом, статами, чертой, кнопкой «Нанять» / «Отказать».
   - **Экран отчёта монстра:** большой текстовый блок (отчёт монстра), подсказка игроку «Интеллект X — доверять на Y%», иконка «возможно лжёт».
   - **Доска заказов:** индикатор «Перехвачено конкурентами» (серый зачёркнутый значок, тусклый текст).
   - **Индикатор угрозы:** визуальный шкала 10% / 20% / 30% / 40%+ с иконками конкурирующих агентств.
   - **Финальный тендер:** бок о бок — твой монстр vs монстр героя, их отчёты, кнопка «Принять решение».

### День 2 — Экраны и обложка
1. **Экраны игры:** главный меню, центр агентства, экран задания, отчёт, конец дня, победа/поражение.
2. **Обложка itch.io:** 630×500 пикселей, отражающая суть игры (человек за столом с монстрами, доска заказов).
3. **Скриншоты/гифка:** 2–3 скриншота для страницы itch.io.

### День 3 — Полировка
1. **Итоговый визуал:** все спрайты в едином стиле, контраст, читаемость.
2. **Экспорт:** все файлы в `assets/art/`, готовы к интеграции программистом.

## Требования к качеству (критерий оценки: Арт-дирекция 20%)
- Единый согласованный стиль (не «подборка из разных коробок»).
- Читаемый интерфейс (понятно, какая кнопка нажать, какой стат у монстра).
- Соответствие жанру и замыслу (агентство монстров, не типичный фэнтезийный герой).

## Файлы, с которыми работаешь
- `docs/art-style.md` — стиль и палитра (уже есть базовая версия, обновить под концепт)
- `assets/art/sprites/` — спрайты монстров, заданий, предметов
- `assets/art/ui/` — кнопки,枠ки, иконки
- `assets/art/bg/` — фон агентства
- `assets/art/fx/` — простые эффекты (мигание, aparición текста)

## Взаимодействие
- С программистом: отдаёшь спрайты с размерами и форматами, консультируешь по интеграции.
- С капитаном: утверждаешь макеты экранов перед финальной отрисовкой.
- С QA: проверяешь, что графика корректно отображается в разных разрешениях.
