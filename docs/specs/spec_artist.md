# Спецификация: Художник (Арт-директор)
## Проект: ПОСЛЕДНИЙ ЧЕЛОВЕК

## Твоя роль в команде
Ты отвечаешь за единство визуального стиля и анимационную подачу. Игра — стратегия с интерфейсом агентства монстров, графика должна быть читательной, но **не статичной**: переходы, микро-анимации, смена контекста должны чувствовать себя как живой кабинет, а не набор кнопок.

## Стек и форматы
- HTML5 Canvas 2D
- PNG (pixel-art) или SVG (вектор)
- Единый стиль для всех ассетов
- ИИ-генерация разрешена, но с ручной доработкой (для отчёта об ИИ)

## Специфика UI-анимации (живой интерфейс, не статичные экраны)

### Экран Агенства (Хаб) — центральный экран
**Фон кабинета:** стол темно-синего цвета (#0b0c10), стена с открытыми дверцами шкафа, карта города в раме над столом.
- **Монстры (слева — досье):** портреты монстров плавно **scale-in** (0→1 за 150 мс) при появлении на собеседовании. При наведении/выборе — легкая подсветка границы (+2 пикселя золота #fbbf24).
- **Доска заказов (справа):** карточки заданий появляются с эффектом **slide-from-right** (300 мс). Если задание «Перехвачено конкурентами» — карточка серая, полупрозрачная (opacity 0.5), крестик сверху, тусклый текст.
- **Панель улучшений (внизу):** 6 карточек плавно **fade-in** при открытии экрана (200 мс интервал между карточками). Внутри каждой карточки:
  - **Стойла:** в левом нижнем углу фона — воротца, за которыми мигают силуэты монстров (каждые 2 сек).
  - **Кузня:** наковальня с искрами — частица молотка раз в 2 секунды.
  - **Канализация:** люк в полу, из которого поднимается пузырь слизи (анимация цикла: вверх → пауза → вниз).
  - **Крипта:** гробовик в тени, периодически крышка откручивается (каждые 5 сек).
  - **Отдел разведки:** карта на стене с красными точками, мигающими в рандомном порядке (шанс перехвата).
  - **Школа лжи:** маска + перо + скролл с зачёркнутым текстом (анимация «письма» каждые 5 сек).
- **Индикатор угрозы:** полоска вверху экрана, цвет меняется: зелёная #4ade80 (10%) → жёлтая #fbbf24 (20%) → оранжевая #f97316 (30%) → красная #f87171 (40%+). Пульсация каждые 2 сек (scale 1.0→1.05→1.0).
- **Кнопка «Начать день»:** появляется после закрытия карточек монстров, имеет subtle hover-эффект (повышение на 1 px, затемнение фона).

### Собеседование (Смена карточки кандидата)
- Старая карточка кандидата **scale-out** (1→0 за 150 мс) влево/вправо с easeOut.
- Новая карточка **scale-in** из центра (0→1 за 150 мс) с easeOut, появляется с задержкой 50 мс после выхода старой.
- У каждого кандидата есть скрытое предпочтение — оно **никогда не показывается напрямую**, но даёт визуальный сигнал: если игрок наводит на задание не подходящего типа — кандидат «нервничает» (микро-анимация дрожания ±1 px раз в 100 мс, 3 раза). Игрок понимает: «ага, preference не с этим типом».

### Задание (Монстр уходит на задание)
- Карточка монстра **slide-out** вправо за 200 мс (easeIn).
- Через 2 секунды (ожидание) — экран отчёта плавно **fade-in** (250 мс).
- В период ожидания: пустой экран агентства с мигающим индикатором угрозы.

### Отчёт (Unreliable Narrator — монстр пишет сам, может врать)
- Экран заполняется пергаментом, который **разворачивается** снизу вверх за 300 мс (scaleY 0→1).
- Текст появляется строкой с задержкой 50 мс каждая (эффект печатания/письма).
- **Если монстр врал (интеллект ≤7):** текст «мерцает» — случайные буквы/слова временно исчезают на 100 мс, затем возвращаются (каждые 1.5 сек). Подсказка: «Интеллект X — доверять на Y%».
- Кнопка «Понятно» появляется после 2 сек, **fade-in** (200 мс).

### Улучшения (Панель внизу хаба)
- При наведении на карточку улучшения — **подсвечивается** (box-shadow +10px, цвет: стойла — зелёный, кузня — золотой, разведка — фиолетовый, лжи — оранжевый).
- При клике «Апгрейд» кнопка сменяет текст: «UP 100» → «Улучшено!» на 1 сек (scale 1.0→1.1→1.0), затем возвращается к новому уровню.
- Уровень отображается числом + полоска прогресса (красный фон → зелёный fill).

### Тендер (Финал, День 14)
- Фон сменяется: появляется стол переговоров, герой-директор в деловом костюме слева, твои монстры справа.
- Оба ряда монстров имеют **микро-анимацию дыхания**: грудная клетка поднимается/опускается (scaleY 1.0→1.02→1.0, цикл 3 сек).
- Задание в центре — световое пятно (radius пульсирует 1.0→1.05).
- Кнопка **«Отправить лучшего»** — появляется после fade-in (400 мс), имеет **glow-эффект** (пульсирующее свечение #a855f7 каждые 2 сек).

### Экраны Победа / Поражение
- Появляется полупрозрачный фон (rgba 0,0,0,0.7) над текущим экраном.
- Текст выводится построчно с задержкой 100 мс каждая (эпичный эффект).
- Кнопка «В главное меню» / «Попробовать снова» — крупный шрифт, **pulse-анимация** (scale 1.0→1.1→1.0 каждые 2 сек).

## Переходы между экранами (таблица для программиста)

| Переход | Тип анимации | Длительность | Детали |
|---|---|---|---|
| Меню → Агентство | Fade (черный) | 300 мс | Затемнение → загрузка → прояснение. Задержка 50 мс перед прояснением для «веса». |
| Агентство → Собеседование | Scale карточки | 150 мс | Старая улетает, новая из центра. |
| Собеседование → Агентство | Reverse scale | 150 мс | Карточка вылетает назад в досье. |
| Агентство → Задание | Slide вправо | 300 мс | Карточка монстра уезжает за край. |
| Задание → Отчёт | Fade | 250 мс | Быстрое переключение фокуса на текст. |
| Отчёт → Агентство | Fade | 250 мс | Возврат к хабу. |
| Агентство → Улучшения | Fade | 250 мс | Оверлей над хабом. |
| Агентство → Тендер | Fade | 400 мс | Драматичнее — чувство финала. |
| Тендер → Победа/Поражение | Fade + смена фона | 500 мс | Плавная смена на стол переговоров. |

**Микро-анимации (все 100-300 мс, easeInOutQuad):**
- Hover кнопок: +1 px scaling + цвет легче на 10%.
- Pulse индикатора угрозы: цикл 4 сек.
- Мерцание текста лжи: 100 мс исчезновение каждые 1.5 сек.
- Particles: искры кузницы (6 частиц/сек), пузырьки канализации (1 пузырь/2 сек), силуэты стойл (мигание).
- Glow кнопки тендера: пульсирующее свечение каждые 2 сек.
