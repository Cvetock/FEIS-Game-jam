### День 2 — Тестирование (функциональное + UI/UX)

#### 1. Тест «на дурака» (расширенный для UI/UX)
- Пройти игру от меню до тендера и обратно **без подсказок**.
- Засечь время каждого перехода (цель: fade 300мс, slide 300мс, scale 150мс — не дольше).
- Проверить каждый из 9 переходов:
  - Меню → Агентство (fade)
  - Агентство → Собеседование (scale)
  - Собеседование → Агентство (reverse scale)
  - Агентство → Задание (slide)
  - Задание → Отчёт (fade)
  - Отчёт → Агентство (fade)
  - Агентство → Улучшения (fade)
  - Агентство → Тендер (fade 400мс)
  - Тендер → Победа/Поражение (fade 500мс)
- **Тест стресс:** быстро кликать по кнопкам во время перехода — состояние не должно ломаться.
- **Тест прерывания:** открыть меню/нажать Esc во время slide-анимации — должно корректно обрабатываться.
- **Читаемость:** текст отчётов читается до конца? typewriter-эффект не слишком медленный?
- **Визуальные подсказки:** понятно ли, что задание перехвачено (серый overlay)? Что монстр врал (мерцание текста)? Что кандидат нервничает (дрожание)? Что overkill (частицы + надпись)?

#### 2. Функциональное тестирование
- **Собеседования:** генерация 3 кандидатов/день, скрытые предпочтения, проверка найма/отказа, дрожание кандидата при неподходящем задании.
- **Задания:** генерация, перехват (шанс = угроза × 0.1 / 0.05), индикатор «Перехвачено» (серый overlay, opacity 0.5, крестик).
- **Результаты заданий:** успех, частичный успех, **overkill** (+150% золота, +1 угроза, 30% травма, частицы разрушения), неудача, исчезновение.
- **Отчёты монстров:** генерация текста по шаблонам, честность = f(интеллект) (≥14=100%, 8-13=50%, ≤7=10%), typewriter-эффект, **мерцание текста при интеллекте ≤7**.
- **Улучшения агентства:** стойла, кузня, канализация, крипта, тренировочный зал, **отдел разведки** (снижает перехват), **школа лжи** (повышает честность). Анимация апгрейда (scale 1.1, текст «Улучшено!»).
- **Индикатор угрозы:** растёт каждые 2 дня (10%→20%→30%→40%+), меняет цвет (зелёный→жёлтый→оранжевый→красный), **пульсирует каждые 4 сек**.
- **Финальный тендер (День 14):** появление Героя-Директора, общее задание, выбор монстров, сравнение отчётов, победа/поражение. Анимации: смена фона, дыхание монстров, glow кнопки.
- **Экраны победы/поражения:** полупрозрачный overlay, построчный вывод текста (100мс/строка), pulse-кнопка.

#### 3. Баланс
- Overkill не доминирующая стратегия (риск +угроза).
- Ложь обнаруживаемая (мерцание + подсказка интеллекта).
- Перехват не блокирует весь прогресс (макс 40% заданий).
- Тендер выигрываем при грамотном выборе монстра.

#### 4. Баги
- Заносить в список с приоритетом: Critical (ломает игру/переходы) > Major (UI не работает) > Minor (визуальные глючи).
- Передавать программисту, приоритизировать с капитаном.
