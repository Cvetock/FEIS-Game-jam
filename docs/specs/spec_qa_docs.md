# Спецификация: QA / Документация
## Проект: ПОСЛЕДНИЙ ЧЕЛОВЕК

## Твоя роль в команде
Ты отвечаешь за качество и соответствие регламенту. Без твоей работы игра не будет допущена до голосования (регламент п. 3.9, 3.10). Ты — последний рубеж перед сдачей.

## Что именно ты должен сделать

### День 1 — Чек-лист и шаблоны
1. **Чек-лист сдачи (`docs/checklist.md`):** уже есть базовая версия — обнови под концепт «ПОСЛЕДНИЙ ЧЕЛОВЕК». Все обязательные пункты регламента:
   - itch.io страница: название, обложка, скриншоты/гифка, описание, управление, ассеты с авторами, ссылка на репозиторий, раздел об ИИ.
   - Репозиторий:公開, файлы `LICENSE` и `ASSETS.md`.
   - Отчёт об использовании ИИ (150–500 слов, шаблон в `docs/ai-report.md`).
   - Игра запускается в браузере (HTML5), без скачивания дополнительного ПО.
   - Полный игровой цикл: начало → процесс → завершение.
   - Нет критических багов.
   - Нет запрещённого контента (п. 3.5 регламента).
   - Нет секретов, ключей, персональных данных в репозитории.
2. **ASSETS.md:** заполняй по мере поступления ассетов от художника и звукорежиссёра (имя, автор, источник, лицензия, где используется).
3. **LICENSE:** MIT (уже создан, проверить).

### День 2 — Тестирование
1. **Тест "на дурака":** пройти игру самому с нуля без подсказок. Записать места, где путаешься.
2. **Функциональное тестирование:**
   - Игра запускается двойным кликом по `index.html`.
   - Генерация монстров и заданий работает.
   - Отправка на задание и расчёт результата корректны.
   - Улучшения агентства применяются.
   - Экраны победы/поражения показываются правильно.
3. **Баги:** заносить в список, передавать программисту, приоритизировать с капитаном.

### День 3 — Сдача и отчёты
1. **Отчёт об ИИ (`docs/ai-report.md`):** заполнить по шаблону п. 3.9 регламента:
   - Инструменты и модели (движок, генераторы кода/арта/звука).
   - Зоны применения ИИ.
   - Пример эффективного приёма (промпт, итерации, доработка).
   - Что сделано без ИИ.
   - Авторы и лицензии сторонних ассетов (ссылка на ASSETS.md).
   - Объём 150–500 слов.
2. **Страница itch.io (`docs/itchio-page.md`):** оформить по шаблону, загрузить билд, скриншоты, описание, управление, ассеты, ссылку на репозиторий, раздел об ИИ.
3. **Репозиторий:** 공개тый, первый коммит после объявления темы (23.10, 18:00), файлы `LICENSE` и `ASSETS.md` в корне.
4. **Финальная проверка:** чек-лист полностью выполнен.

## Файлы, с которыми работаешь
- `docs/checklist.md` — чек-лист сдачи (уже есть)
- `docs/ai-report.md` — шаблон отчёта об ИИ (уже есть)
- `docs/itchio-page.md` — черновик страницы itch.io (уже есть)
- `ASSETS.md` — таблица сторонних ассетов (уже есть, заполняешь)
- `LICENSE` — MIT (уже есть)

## Взаимодействие
- С программистом: принимаешьビルд, тестируешь, сообщаешь баги.
- С художником и звукорежиссёром: собираешь информацию об ассетах для `ASSETS.md`.
- С капитаном: координируешь сроки сдачи, фиксируешь готовность к публикации.

## Самые рискованные регламентные требования
1. **Отчёт об ИИ обязателен** — без него проект снимается с голосования.
2. **Первый коммит только после 18:00** — иначе дисквалификация за использование достартовой заготовки.
3. **Публичный репозиторий с LICENSE и ASSETS.md** — без этих файлов нарушение регламента.
4. **HTML5 на itch.io без внешних рантаймов** — игра должна запускаться в браузере напрямую.
