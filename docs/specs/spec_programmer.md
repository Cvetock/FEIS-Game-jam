# Спецификация: Программист
## Проект: ПОСЛЕДНИЙ ЧЕЛОВЕК

## Твоя роль в команде
Ты отвечаешь за весь код игры. Игра работает в браузере (HTML5 Canvas 2D), без шага сборки, без библиотек. Твоя задача — сделать так, чтобы вся логика агентства, собеседований, заданий, нечестных отчётов, overkill, конкурентов и финального тендера работала без критических багов. **UI не должен выглядеть статичным** — все переходы, микро-анимации, индикаторы должны быть живыми.

## Стек (обязательно)
- Чистый JavaScript (ES2020+)
- HTML5 Canvas 2D
- Без Node/npm, без сборщиков, без внешних библиотек
- Запуск: двойным кликом по `index.html`

## Что именно ты должен сделать

### День 1 — Каркас, ядро и система переходов

1. **Структура проекта** (уже частично готова):
   - `index.html` — точка входа
   - `src/main.js` — игровой цикл, состояния (меню / агентство / собеседование / задание / отчёт / улучшения / тендер / победа / поражение)
   - `src/game.js` — менеджер состояний игры с системой переходов
   - `src/input.js` — мышь, клавиатура, тач
   - `src/renderer.js` — отрисовка экранов, UI-элементы, **анимации переходов**, частицы, пульсации
   - `src/assets.js` — загрузка картинок и звуков
   - `src/audio.js` — Web Audio API (SFX + музыка)
   - `src/utils.js` — утилиты (случайные числа, статы, easing-функции, расчёт результатов)

2. **Модель данных** (расширенная для UI):
   - **Монстр:** имя, вид, статы (сила, ловкость, интеллект, удача), черта, **предпочтение (preference)**, статус, **анимационное состояние** (idle, nervous, leaving, overkill, injured, lost).
   - **Задание:** название, сложность, награда, риск, требуемый вид, **перехвачено (boolean)**, **анимационное состояние** (available, intercepted, completed).
   - **Предмет:** тип, бонусы
   - **Агентство:** уровень, улучшения (стойла, кузня, канализация, крипта, тренировочный зал, отдел разведки, школа лжи), золото, угроза героев
   - **Игровое состояние:** день, штат монстров, доступные кандидаты, доска заказов, история отчётов, **текущий экран**, **состояние перехода**
   - **Результат задания:** тип (успех / частичный успех / overkill / неудача / исчезновение), золото, угроза, травма, **отчёт монстра (текст, честный/ложный, анимация мерцания)**

3. **Система переходов (обязательно для MVP):**
   ```javascript
   // В src/game.js
   const TRANSITION_MAP = {
     'menu->agency': { type: 'fade', duration: 300 },
     'agency->interview': { type: 'scale', duration: 150 },
     'interview->agency': { type: 'scale', duration: 150 },
     'agency->mission': { type: 'slide', duration: 300 },
     'mission->report': { type: 'fade', duration: 250 },
     'report->agency': { type: 'fade', duration: 250 },
     'agency->upgrade': { type: 'fade', duration: 250 },
     'agency->tender': { type: 'fade', duration: 400 },
     'tender->victory': { type: 'fade', duration: 500 },
     'tender->defeat': { type: 'fade', duration: 500 }
   };

   function setState(newState) {
     const transition = TRANSITION_MAP[`${this.state}->${newState}`] || { type: 'fade', duration: 300 };
     // 100мс пауза перед стартом
     setTimeout(() => {
       startTransition(transition.type, this.state, newState, () => {
         this.state = newState;
         this.onStateEnter(newState);
       });
     }, 100);
   }
   ```
   - Реализовать `startTransition(type, from, to, onComplete)` в `src/renderer.js`.
   - Поддерживаемые типы: `'fade'`, `'slide'`, `'scale'`.
   - Все анимации используют `easeInOutQuad(t)`.

4. **Микро-анимации (функции в renderer/utils):**
   - `easeInOutQuad(t)` — плавность для всех анимаций.
   - `hoverEffect(element)` — +1 px scaling + цвет легче на 10% (requestAnimationFrame loop).
   - `pulseElement(element, cycleMs)` — scale 1.0→1.05→1.0 каждые `cycleMs`.
   - `shakeElement(element, intensity, times)` — для нервного кандидата (±1 px).
   - `particleSystem` — массив частиц, `update(dt)`, `render(ctx)`:
     - Кузня: 6 искр/сек, время жизни 200 кадров.
     - Канализация: 1 пузырь/2 сек, подъём вверх 30 px за 1.5 сек.
     - Стойла: мигающие силуэты (opacity 0→1→0 за 1 сек каждые 2 сек).
   - `typewriterEffect(text, lineDelay)` — печать текста по строкам.
   - `flickerText(text, intensity)` — мерцание букв для лжи.

5. **Генерация монстров:** случайные имя, вид, статы (1–20), черта, **предпочтение (preference)**.
6. **Генерация заданий:** случайные название, сложность, награда, риск, **перехвачено = threat × 0.1 (или 0.05 с разведкой)**.
7. **Экран агентства (хаб):** отрисовка списка монстров в штате, **кандидаты на собеседование (3 в день)** с scale-in анимацией, доска заказов (с серыми intercepted карточками, slide-in), панель улучшений (fade-in карточек по очереди), индикатор угрозы (пульсация).

### День 2 — Логика заданий, отчётов, конкурентов, роуглайк и переходы

1. **Система заданий:** выбор монстра + задание → авто-расчёт результата (статы + экипировка + случайность) → определение типа результата (успех / частичный успех / **overkill** / неудача / исчезновение).
2. **Overkill:** если результат превышает сложность на 50%+ → +150% золота, +1 угроза, 30% шанс травмы. **Анимация:** частицы разрушения (дерево/ферма) летят наружу 300 мс.
3. **Отчёт монстра (Unreliable Narrator):** генерация текста из шаблонов (`docs/content.md`). Честность = f(интеллект):
   - Интеллект ≥ 14: 100% честный
   - Интеллект 8–13: 50% честный
   - Интеллект ≤ 7: 10% честный
   Игрок видит **только текст отчёта** с `typewriterEffect`, не истинный результат. Если ложь — `flickerText`.
4. **Экраны отчёта:** показ пергамента (scaleY 0→1 за 300 мс), текст печатается, кнопка «Понятно» fade-in через 2 сек.
5. **Перехват заданий:** при генерации доски — `rival_take_chance = threat × 0.1 (или 0.05 с разведкой)`. Перехваченные карточки: opacity 0.5, серый overlay, крестик, тусклый текст.
5. **Между днями:** трата золота на улучшения (стойла, кузня, канализация, крипта, тренировочный зал, **отдел разведки**, **школа лжи**). При апгрейде — анимация кнопки (scale 1.1, текст «Улучшено!» 1 сек).
6. **Роуглайк-прогрессия:** уровень агентства растёт, **угроза героев растёт каждые 2 дня** (10% → 20% → 30% → 40%+), шанс перехвата пересчитывается. Индикатор угрозы меняет цвет + пульсирует.
7. **Финальный тендер (День 14 / уровень 5):**
   - Появляется «Герой-Директор» с набором монстров.
   - Общее финальное задание. Игрок и ИИ выбирают монстров.
   - Сравнение отчётов по скрытым критериям (качество + честность + предпочтения).
   - Победа/поражение на основе тендера.
   - Анимация: фон смена (fade 400мс), дыхание монстров (scaleY 1.0→1.02), glow кнопки.
8. **Условия победы/поражения:** выжить 14 дней + выиграть тендер, или город теряется (угроза ≥ 100% / нет монстров / проигрыш в тендере).

### День 3 — Полировка, багфиксы и билд
1. **Все 9 переходов** работают без задержек, миганий, застреваний.
2. **Паузы 100мс** перед переходами ощущаются, но не раздражают.
3. **Индикатор угрозы:** пульсация синхронизирована, цвет меняется при смене ступени.
4. **Overkill частицы** появляются и исчезают корректно.
5. **Ложь мерцание** работает только при интеллекте ≤7.
6. **Собеседование:** дрожание кандидата при неподходящем задании.
7. **Тест на дурака:** меню → агентство → собеседование → задание → отчёт → улучшения → тендер → победа/поражение — весь цикл без багов.
8. **Локальное хранилище** (опционально): сохранение прогресса.
9. **Билд для itch.io:** собрать файлы, проверить `index.html` без сервера.
10. **README:** как запустить игру.

## Технические ограничения
- Не более 3-4 видов монстров в MVP.
- Не более 15 типов заданий.
- Не более 8-10 карт улучшений агентства.
- **Анимации MVP:** fade, slide, scale, hover, pulse индикатора, typewriter текст, flicker лжи.
- **Пост-MVP (если время):** particles кузницы/канализации/стойл, glow кнопки, дыхание монстров.
