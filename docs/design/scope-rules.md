# Правила скоуп-контроля

## Что считаем MVP (минимальная законченная игра)
- Полный игровой цикл: начало → игровой процесс → завершение (победа/поражение).
- ゲーム запускается в браузере без скачивания (HTML5).
- Есть управление, описанное на странице itch.io.
- Нет критических багов, которые блокируют запуск или прохождение.
- Есть полный набор обязательных файлов: LICENSE, ASSETS.md, отчёт об ИИ.

## Как определять, что вырезать
- Если фича не укладывается в оставшееся время — вырезаем сразу, не доводим до «почти готово».
- Приоритет: core loop > полировка > стрейч-механики.
- Маленькая законченная игра всегда лучше большого долгостроя.

## Чек-лист «минимальная законченная игра»
- [ ] Игра запускается двойным кликом по index.html (или открывается на itch.io).
- [ ] Есть начало (меню/старт), процесс и завершение (экран победы/поражения).
- [ ] Управление работает (мышь/клавиатура).
- [ ] Нет критических багов (игру можно пройти до конца).
- [ ] Страница itch.io оформлена (описание, управление, скриншоты).
- [ ] Репозиторий公開ный, есть LICENSE и ASSETS.md.
- [ ] Отчёт об ИИ опубликован (150–500 слов).
