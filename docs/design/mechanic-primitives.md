# Механики-примитивы для Canvas 2D (сложность 1–2 дня каждая)

## Движение и ввод
1. Движение персонажа/курсора по мыши или WASD (просто)
2. Клик по объекту на canvas (просто)
3. Перетаскивание (drag & drop) объектов (средне)

## Игровой мир
4. AABB-коллизии между прямоугольниками (просто)
5. Таймер/отсчёт до события (просто)
6. Волны: спавн врагов/intervallом, волна → пауза → следующая волна (средне)
7. Сетка/тайловая карта (просто)

## Стратегия / рогулайтик
8. Постройка объекта на свободной клетке (средне)
9. Улучшение объекта (уровень + характеристики) (просто)
10. Ресурсы: заработок / трата / отображение (просто)
11. Юниты: движение из точки А в точку Б (средне)
12. Боевой урон и здоровье (HP) (просто)
13. Поиск пути простым маршрутом (для戦егического перемещения) (средне)
14. Перманентная смерть + прогрессия между забегами (средне)

## UI
15. ХUD: счет, HP, волна, ресурсы (просто)
16. Кнопка меню / пауза (просто)
17. Экран начала и конца игры (просто)

## Эффекты
18. Взрыв/частицы простые (средне)
19. Мигание/подсветка объекта (просто)
20. Текст Floating Damage над целью (средне)
