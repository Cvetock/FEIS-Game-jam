# Стиль графики (предварительный)

## Направление
Pixel-art 2D. Чёткие силуэты, ограниченная палитра, единый стиль для всех объектов.

## Палитра (HEX)
- Фон: #0b0c10 (тёмно-синий/чёрный)
- Основной объект: #4ade80 (зелёный)
- UI/акцент: #fbbf24 (жёлтый)
- Враг/опасность: #f87171 (красный)
- Текст: #f1f5f9 (белый)

## Разрешение / тайл
Базовый размер ячейки: 32×32 пикселя. Холст игры: 640×480.

## Правила читаемости
- Высокий контраст между объектом и фоном.
- Силуэты узнаваемы даже в уменьшении.
- Единая толщина обводки и стиль пикселей.

## План после объявления темы
- Персонаж/юниты (спрайт 32×32, idle + движение)
- 2–3 типа объектов/врагов
- Фон (сетка/поле)
- UI-элементы (кнопки, HUD, экран начала/конца)
- Обложка itch.io 630×500
- Скриншоты / гифка для страницы

## Инструменты
Пиксель-арт редактор (Aseprite или онлайн-аналог), возможно ИИ-генерация с дорисовкой вручную (для отчёта об ИИ).
