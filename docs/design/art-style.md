# Стиль графики (векторный)

## Направление
Векторная графика (SVG) для HTML5 Canvas 2D. Чёткие силуэты, ограниченная палитра, единый стиль для всех объектов. Тематика: кабинет агентства монстров, бумаги, доска заказов, портреты монстров с эмоциями. Все ассеты масштабируются без потери качества.

## Палитра (HEX)
- Фон кабинета: #0b0c10 (тёмно-синий/чёрный)
- Основной акцент (золото/успех): #fbbf24 (жёлтый)
- Успех/честность: #4ade80 (зелёный)
- Опасность/overkill/конкуренты: #f87171 (красный)
- Ложь/подозрение: #f97316 (оранжевый)
- Текст/UI: #f1f5f9 (белый)
- Перехвачено/недоступно: #64748b (серый)
- Герой-директор/тендер: #a855f7 (фиолетовый)

## Разрешение / тайл
Базовый размер иконки: 64×64 (вектор, масштабируется). Холст игры: 640×480.

## Правила читаемости
- Высокий контраст между объектом и фоном.
- Силуэты узнаваемы даже в уменьшении (до 32×32).
- Единая толщина обводки (2px для контуров, 1px для деталей).
- Текст отчётов монстров читаем (минимум 14px, контрастный фон).
- Все градиенты линейные/радиальные, без растровых текстур.
