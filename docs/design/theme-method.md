# Методика выбора концепта (после объявления темы)

## За 30–60 минут:
1. **Обсуждение 3–5 идей** — каждая должна укладываться в две предложения и в жанр «2D стратегия-роуглайк».
2. **Отбор по трём критериям:**
   - **Реальность MVP за ~2 дня** — можно ли сделать минимальный рабочий цикл на Canvas 2D + чистый JS.
   - **Глубина раскрытия темы** — тема не просто упоминается, а лежит в основе механики.
   - **Fun** — хочется ли играть «ещё один забег».
3. **Выбор одного концепта** —リード (gamedesigner) ставит точку, если спор дольше 15 минут (по регламенту).

## Примеры направлений для стратегии-роуглайка (заготовки)
- Базовое поселение + волны врагов + улучшения между забегами.
- Управление отрядом юнитов на процедурной карте, перманентная смерть.
- Построение обороны в реальном времени, случайные события.
