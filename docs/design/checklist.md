## Чек-лист механик (внутренний)
- [ ] **Собеседования (найм):** 3 кандидата в день, скрытые предпочтения, проверка найма/отказа, стоимость в золоте (20 + avgStat×2.5)
- [ ] **Задания:** генерация 4 шт., сложность, награда, риск, требуемый вид
- [ ] **Перехват заданий:** шанс = угроза × 0.1 (с разведкой ×0.5), индикатор «Перехвачено»
- [ ] **Групповая отправка:** до 3 монстров, силы суммируются, один общий отчёт от самого умного
- [ ] **Результаты заданий:** успех, частичный успех, overkill (+150% золота, +3% угрозы, риск травмы), неудача, исчезновение
- [x] **Отчёты монстров:** текст по шаблонам, честность = f(ИНТ) (≥14=100%, 8–13=50%, ≤7=10%), для группы — от лучшего ИНТ
- [x] **Улучшения агентства:** стойла, кузня, канализация, крипта, тренировочный зал, отдел разведки, школа лжи
- [ ] **Угроза героев = конкуренты:** растёт каждые 2 дня (10% → 20% → 30% → 40%+), оверкилл +3%
- [ ] **Финальный тендер (День 14):** Герой-Директор, общее задание (сложность 8), сравнение отчётов, победа/поражение
- [x] **Роуглайк:** новый запуск = новые монстры, предпочтения, задания
- [ ] **Увольнение монстров:** кнопка в досье (только idle), освобождает слот в штате
- [x] **Сохранение/загрузка:** localStorage (ключ feis_last_human_v1), автосейв, меню с продолжением «день N»
- [x] **Пауза / Помощь / Пролог:** Esc → пауза (продолжить/помощь/в меню), кнопка «КАК ИГРАТЬ», интро с таймером и пропуском
- [ ] **Адаптивный UI (1280×720):** относительные координаты (%), полноэкранный канвас, HiDPI, тач-ready
- [ ] Игра запускается в браузере (HTML5) — без скачивания дополнительного ПО
