## Чек-лист механик (внутренний)
- [ ] **Собеседования (найм):** 3 кандидата в день, скрытые предпочтения, проверка найма/отказа
- [ ] **Задания:** генерация, сложность, награда, риск, требуемый вид
- [ ] **Перехват заданий:** шанс = угроза × 0.1 (0.05 с разведкой), индикатор «Перехвачено»
- [ ] **Результаты заданий:** успех, частичный успех, **overkill** (+150% золота, +1 угроза, 30% травма), неудача, исчезновение
- [ ] **Отчёты монстров:** текст отчёта генерируется по шаблонам, честность = f(интеллект) (≥14=100%, 8-13=50%, ≤7=10%)
- [ ] **Улучшения агентства:** стойла, кузня, канализация, крипта, тренировочный зал, **отдел разведки**, **школа лжи**
- [ ] **Угроза героев = конкуренты:** растёт каждые 2 дня (10% → 20% → 30% → 40%+)
- [ ] **Финальный тендер (День 14 / Уровень 5):** Герой-Директор, общее задание, сравнение отчётов, победа/поражение
- [ ] **Роуглайк:** новый запуск = новые монстры, предпочтения, задания
