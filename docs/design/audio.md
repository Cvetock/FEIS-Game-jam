# Аудиоплан

## SFX (типовые события)
- клик / выбор (click)
- **найм монстра (hire)** — радостный, уверенный
- **отказ монстра (reject)** — грустный, отвергнутый
- отправка на задание (depart)
- возвращение успешное (success)
- **overkill (перестарался)** — мощный, разрушительный звук + звук монет (звон)
- возвращение с травмой / неудача (fail / injury)
- **исчезновение монстра (lost)** — пустой, эхающий
- **ложь в отчёте (lie_detected / lie_hint)** — тихий подозрительный звук (шёпот, лёгкий смешок, скрип пера)
- **перехват задания конкурентами (rival_take)** — звук «уходящего» заказа (щёлк, свист), тревожный аккорд
- улучшение агентства (upgrade)
- начало нового дня (new_day)
- **финальный тендер (tender_start)** — напряжённая, торжественная музыка
- победа (win)
- поражение (lose)

## Музыка
- **Меню / Кабинет агентства:** спокойная, слегка странная петля (1–2 минуты, зацикленная). Атмосфера: бумаги, тихое рычание за стеной, скрип пера.
- **Экран отчёта:** более напряжённая, но не отвлекающая от чтения текста.
- **Финальный тендер:** драматическая, деловая музыка (тендерная битва).
- **Победа:** тёплая, умиротворённая.
- **Поражение:** холодная, пустая.

## Источники
- Бесплатные библиотеки: Open Game Art, Kenney.nl, Freesound, NASA Sound Library, BBC Sound Effects, Incompetech, Free Music Archive, Musopen, Sonniss (CC0 / CC-BY).
- Синтез через Web Audio API (короткие SFX без файлов — см. сниппет в `src/audio.js`).
- **Overkill, ложь, перехват, тендер** — лучше синтезировать через Web Audio API для уникальности и отсутствия лицензий.

## Структура
assets/audio/sfx/ — короткие звуки
assets/audio/music/ — петли
assets/audio/ambient/ — фоновый шум (шорох пергамента, скрип дверей, далекое рычание)

## Сниппет Web Audio API (для программиста)
Функция `Audio.playSfx(type)` уже реализована в `src/audio.js`. Новые типы:
- `hire`, `reject`, `overkill`, `lie`, `rival_take`, `tender`
