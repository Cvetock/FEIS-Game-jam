# Реестр ассетов проекта «ПОСЛЕДНИЙ ЧЕЛОВЕК» (FEIS Game Jam 2026)

## Примечание для жюри (регламент п. 3.9)

> Все графические ассеты проекта созданы участниками команды вручную с использованием ИИ-инструментов (Stable Diffusion, Midjourney) как вспомогательных средств для доработки, апскейла, стилизации. Полные исключительные интеллектуальные права на все материалы принадлежат команде проекта «ПОСЛЕДНИЙ ЧЕЛОВЕК». Никаких сторонних заимствований не используется.
