# ПОСЛЕДНИЙ ЧЕЛОВЕК

2D-стратегия-роуглайк про агентство по трудоустройству монстров. Герои ушли в другие
измерения, город остался без защитников — и последний человек открывает контору, которая
отправляет гоблинов и скелетов пугать бандитов. Монстры не подчиняются: они торгуются,
отказываются и врут в отчётах.

**Жанр:** стратегия / менеджмент с роуглайк-забегом на 14 дней.
**Стек:** HTML5 Canvas 2D + чистый JavaScript (ES2020), без сборки и внешних библиотек.

## Как запустить

Откройте `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).
Ни сервер, ни установка не нужны. Для публикации на itch.io достаточно загрузить папку
целиком (`index.html`, `src/`, `assets/`).

## Управление

- **Мышь / тап** — все действия: вкладки, карточки, кнопки.
- **Enter / Space** — подтвердить (меню, пролог, отчёт, конец дня).
- **Esc** — пауза в агентстве, закрыть отчёт/помощь, выйти из досье.
- Игра сама сохраняется в `localStorage` после каждого действия; в меню появится
  «ПРОДОЛЖИТЬ».

## Игровой цикл

1. **Собеседование.** 3 кандидата в день, у каждого скрытое предпочтение. Найм бесплатный,
   но тратит 1 из 3 попыток; отказ — тоже. Найм сверх лимита стойл невозможен.
2. **Заказы.** На доске 4 заказа: сложность, награда, риск. Часть заказов перехватили
   конкуренты — они серые и недоступны. Монстр выполняет **одно задание в день**, потом
   отдыхает (раненый пропускает день).
3. **Отчёт.** Монстр пишет докладную сам, и её текст зависит от интеллекта:
   - ИНТ ≥ 14 — честен;
   - ИНТ 8–13 — честен в половине случаев;
   - ИНТ ≤ 7 — врёт почти всегда, текст мерцает.
   Игрок видит **только текст** — реальный результат и золото откроются в конце дня.
4. **Оверкилл.** Монстр может перестараться: +50% золота, но +3% угрозы и риск травмы.
5. **Конец дня.** Итоги, начисление золота, рост угрозы, новые кандидаты и заказы.
6. **Улучшения и экипировка.** 7 улучшений (стойла, кузня, канализация, крипта,
   тренировочный зал, отдел разведки, школа лжи) и 12 предметов: оружие, броня, амулеты,
   расходники. Экипировка выдаётся в досье монстра.
7. **Финал.** На 14-й день — тендер с Героем-Директором: оба выставляют лучшего монстра,
   сравниваются отчёты (статы против сложности 8, честность, предпочтения). Выигрывает
   тот, чей отчёт убедительнее.

## Победа и поражение

- **Победа** — дожить до 14-го дня и выиграть тендер.
- **Поражение** — проиграть тендер или довести угрозу конкурентов до 100% (город забирают).
- Роуглайк: после финала «НОВАЯ ИГРА» генерирует новых монстров, заказы и предпочтения.

## Баланс (значения в игре)

| Параметр | Значение |
|---|---|
| Стартовые деньги | 100 золота |
| Награда заказа | 10–80 (overkill ×1.5, частичный успех ×0.5) |
| Стоимость улучшений | 40–100 за уровень, растёт |
| Стоимость предметов | 20–100 |
| Угроза | старт 10%, +5%/день, −2%/день с разведкой, +3% за оверкилл |
| Перехват заказов | 10 / 20 / 30 / 40% по ступеням, ×0.5 с разведкой |
| Собеседования | 3 в день |
| Штат | 4 (+2 со стойлами) |
| Забег | 14 дней, затем тендер |

Проверено симуляцией (2000 забегов на стратегию): аккуратная игра с разведкой и
экипировкой выигрывает ~64%, без разведки — ~38%, случайные действия — ~18%.
Поражение по угрозе достижимо при агрессивной игре без «Отдела разведки».

## Структура

```
index.html          точка входа
src/main.js         экраны, ввод, переходы, сохранение
src/models.js       вся игровая математика (найм, задания, отчёты, тендер)
src/content.js      имена, заказы, тексты отчётов, черты
src/renderer.js     примитивы рисования, тема, перенос текста
src/assets.js       загрузчик PNG/SVG
src/audio.js        синтезированные SFX (Web Audio)
src/input.js        мышь, тач, клавиатура
src/game.js         цикл и state-машина
src/utils.js        рандом, clamp, uid
assets/art/         графика художника
docs/               ГДД, баланс, контент, отчёты
```
