# ПОСЛЕДНИЙ ЧЕЛОВЕК

2D-стратегия-роуглайк про агентство по трудоустройству монстров. Герои ушли в другие
измерения, город остался без защитников — и последний человек открывает контору, которая
отправляет гоблинов, орков, скелетов, слизней, импов, троллей и вампиров пугать бандитов.
Монстры не подчиняются: они торгуются, отказываются и врут в отчётах.

**Жанр:** стратегия / менеджмент с роуглайк-забегом на 14 дней.
**Стек:** HTML5 Canvas 2D + чистый JavaScript (ES2020), без сборки и внешних библиотек.
**Разрешение:** 1280×720 (16:9 HD), HiDPI, тач-ready.

---

## Как запустить

Откройте `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).
Ни сервер, ни установка не нужны. Для публикации на itch.io достаточно загрузить папку
целиком (`index.html`, `src/`, `assets/`, `new graphics/`).

---

## Управление

- **Мышь / тап** — все действия: вкладки, карточки, кнопки, попапы.
- **Enter / Space** — подтвердить (меню, пролог, отчёт, конец дня).
- **Esc** — пауза в агентстве, закрыть отчёт/помощь, выйти из досье.
- Игра сама сохраняется в `localStorage` (автосейв: конец дня, меню, победа/поражение);
  в меню появится **«ПРОДОЛЖИТЬ · день N»**.

## Интерфейс 

- **Верхняя панель — Ростер** (сворачивается/разворачивается кнопкой справа):
  ресурсы , 6 слотов монстров с портретами,
  статусом (здоров/ранен), уровнем и чертой. Заблокированные слоты — требуют улучшение «Стойла».
- **Центральная зона** — пергамент с 4 вкладками (переключение нижней навигацией):
  1. **ТАВЕРНА (Найм)** — 3 кандидата/день: портрет, имя `[Ур.X]`, вид, черта, 4 статы,
     стоимость найма , 3 собеседования/день.
  2. **КАРТА (Задания)** — доска 4 заданий (2×2): иконка, название, сложность, риск, награда,
     рекомендованный вид (+2 к статам). Перехваченные — серые с крестом.
     30% шанс спец. задания: `[ГРУППА]` (≥2 монстра) / `[СОЛО-ЭПИК]` (1 монстр).
     Чипы монстров (макс 3) → «Шанс группы: XX%» → «ОТПРАВИТЬ».
  3. **МАГАЗИН (Улучшения)** — 7 улучшений (экспоненциальные цены `baseCost×1.5^lvl`):
     стойла, кузня, канализация, крипта, тренировка, разведка, школа лжи.
     Внизу — «НАНЯТЬ НЕЖИТЬ» за 150 зол. (скелет/вампир).
  4. **РЫНОК (Экипировка)** — 5 предметов: оружие, броня, амулеты, зелье, эликсир.
- **Нижняя навигация (5 кнопок):** Таверна / Карта / Закончить день / Магазин / Рынок.

## Игровой цикл (день 1 — 14)

### Найм
3 случайных кандидата из 7 видов: **гоблин, орк, скелет, слизь, импу, тролль, вампир**.
У каждого — скрытое **предпочтение** (13 видов) и **черта** (10 шт.).
Найм = 1 собеседование + золото (`20 + avgStat×2.5`). Отказ = потеряно собеседование, золото не списалось.

### Задания
7 типов: **farm, caravan, stables, cave, ruins, citadel, lieschool**.
Сложность, риск, награда, рекомендованный вид (+2 к статам).
**Перехват** конкурентами: шанс = стадия_угрозы × 0.1 (разведка ÷2).
**Спец. задания** (30%): `[ГРУППА]` / `[СОЛО-ЭПИК]` (сложность+2, награда×2.5).
**Групповая отправка** — до 3 монстров, силы суммируются, общий отчёт от лучшего ИНТ.

### Миссия и отчёт
Монстр уходит → прогресс-бар 2 сек → **отчёт пишется по буквам** (машина пишущая).
**Честность = f(ИНТ)**: ≥14 = 100% правда, 8–13 = 50%, ≤7 = 10% (школа лжи ×0.75).
Игрок принимает отчёт → золото начисляется.

### Конец дня
Модалка **«ЗАВЕРШИТЬ ДЕНЬ?»** (ДА/ОТМЕНА) → статистика дня → угроза +3.5%/день
(easy +2%, hard +5%), оверкилл штраф по сложностям (easy +2%, normal +3%, hard +6%).
Разведка: угроза −2%/день, перехват ÷2. Автосейв, новые кандидаты/заказы.

## Прогрессия и мета

- **7 видов монстров**: гоблин, орк, скелет, слизь, импу, тролль, вампир (уникальные bias статов).
- **Прогрессия монстров**: XP за успех → лвл-ап на `level*2` XP → +1 ко всем статам.
- **Травмы**: `injuryDays` (easy 1, normal 2, hard 3), лечение зельем, эликсир +5 СИЛЫ на 1 квест.
- **Увольнение** — кнопка в досье (только idle), экипировка возвращается в сумку.
- **Экипировка попап** — клик по пустому слоту в досье → модалка выбора из сумки.
- **Расходники в досье** — отдельный блок «РАСХОДНИКИ (СУМКА)».
- **Туториалы** (4 контекстных): найм, задания, досье, конец дня.
- **Подтверждение конца дня** — модалка «ЗАВЕРШИТЬ ДЕНЬ?» (ДА/ОТМЕНА).
- **Справка по статам** — кнопка «?» в ростере.
- **Пауза (Esc)** — ПРОДОЛЖИТЬ / КАК ИГРАТЬ / В МЕНЮ (с автосейвом).
- **Пролог** — анимированный текст, клик = пропуск.
- **Меню** — выбор сложности: **Easy / Normal / Hard** (разные стартовые параметры).

## Финал: День 14 — Тендер
Если дожил до 14 дня и есть ≥1 монстр → финальный тендер.
Выбираешь чемпиона, ИИ-Герой — своего. Задание: цитадель (сложность 8).
Побеждает тот, чей отчёт **убедительнее** (статы + честность + предпочтение).
ИИ получает бафф +3 к счёту.

---

## Победа / Поражение
- **Победа** — дожить до 14 дня и выиграть тендер.
- **Поражение** — проиграть тендер / угроза 100% / 0 монстров на тендере.
- Роуглайк: новая игра = новые монстры, черты, предпочтения, задания.
