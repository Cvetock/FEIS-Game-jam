# FEIS Game Jam — 2D Стратегия-Роуглайк

Как запустить: просто откройте `index.html` в любом современном браузере. Сервер и установка не требуются.

## Структура
- `index.html` — точка входа
- `src/` — код игры (main, game, input, renderer, assets, audio, utils)
- `assets/art/` — графика
- `assets/audio/` — звук и музыка
- `docs/` — геймдизайн, чек-листы, отчёты

## Стек
HTML5 Canvas 2D + чистый JavaScript (ES2020+), без шага сборки и внешних библиотек.
